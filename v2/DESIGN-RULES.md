# قواعد تصميم أديب V2 — قانون التصميم المعتمَد

> القانون التصميميّ المعتمَد للنسخة الثانية. كل قاعدة هنا **مُقَرّة من المالك**، وتُطبَّق في الكود **حرفيًّا** بلا اجتهاد ولا تبسيط. عند أيّ تعارض، هذا الملفّ يفوز على أيّ افتراض أو ذاكرة.
>
> **تعليمة لكلود:** اقرأ هذا الملفّ كاملًا قبل أيّ عمل تصميميّ/واجهة. لا تُضِف قاعدة دون إقرار المالك، ولا تعدّل نصّه دون إذنه.

---

## القاعدة ١ — حارس الهوية

- **مصدر واحد:** كل تنسيق من الهوية فقط (`tokens.css` للرموز · `components.css` للمكوّنات). ممنوع تعريف لون أو صنف جديد خارجهما، وممنوع `#hex` صريح — دائمًا `var(--…)`.

- **عند طلب عنصر جديد، ثلاثة مسارات لا رابع لها:**
  1. **يوجد مكوّن مناسب في المكتبة** ← استعمله كما هو.
  2. **طُلِب صراحةً «صمّم مكوّنًا جديدًا»** ← يُبنى **في المكتبة** (`components.css` + صفحة في `/ui`) بالهوية، ثم يُستعمل. (نموّ المكتبة «حبة حبة».)
  3. **لا مكوّن، ولم يُطلَب تصميمه** ← يُوسَم `data-needs="اسم المكوّن"` ويُترك **كما هو بلا أيّ تنسيق**، فيظهر صارخًا «🚧 يحتاج مكوّن».

- **الممنوع المطلق:** أيّ تنسيق شارد (CSS مؤقّت في شاشة أو inline) خارج المكتبة — أبدًا.

- **الكاشف:** كاشف التطوير (`data-guardrail`) يمسك أيّ عنصر خام بلا مكوّن — لا يُتجاهَل. **جرد النواقص:** `grep -rn data-needs`.

## القاعدة ٢ — الزوايا المتراكزة (Concentric)

**المبدأ:** كل الزوايا من **عائلة واحدة** (منحنى العلامة)، والعنصر المتداخل زاويته **موازية** لأبيه — الأب ناقص الفراغ بينهما. رمز أساس واحد `--radius`، والباقي **مشتقّ منه بـ `calc`** — غيّر الأساس فيتبعه الكلّ والتراكز يضبط نفسه.

**السلّم (في `tokens.css` — المصدر الوحيد):**
- **`--radius` = 16px** ← الأساس: الأسطح والعناصر ≥ 40px (كروت · أزرار · حقول · نوافذ).
- **`--radius-nested` = `calc(--radius − 3px)` = 13** ← المتداخل الملاصق بفراغ 3px (زرّ المبدّل داخل حاويته) — **متراكز**، منحناه موازٍ للأب.
- **`--radius-sm` = `calc(--radius − 6px)` = 10** ← الصغير القائم بذاته (28–38px): أفتار صغيرة · أزرار أيقونات · ترقيم — عشان ما ينقلب دائرة.
- **`--radius-xs` = `calc(--radius − 10px)` = 6** ← الصغير جدًّا (~22px): checkbox.
- **`--radius-full` = 9999** ← كبسولة وظيفيّة: المفتاح (switch) + الشارات pill.
- **الدوائر الوظيفيّة** (نقاط · راديو · مقبض · سبينر) = `border-radius: 50%` مباشرةً.

**القاعدة عند أيّ عنصر جديد:**
- سطح/عنصر كبير (≥ 40px) → `var(--radius)`.
- عنصر **داخل** أبيه وملاصق له → `calc(var(--radius) − الفراغ)` (أو `--radius-nested` للفراغ 3px) → **متراكز**.
- صغير قائم بذاته → `--radius-sm` (أو `--radius-xs` للصغير جدًّا) — لا ينقلب دائرة.
- **ممنوع أيّ قيمة px صريحة** — من الرموز فقط. غيّر `--radius` في `tokens.css` → يتبع الموقع كلّه.

**التطبيق (المصدر الوحيد):** كتلة «نظام الزوايا المتراكز» في آخر `components.css` (تُحمَّل أخيرًا، بلا `!important`) — تُسند الاستثناءات فوق الأساس.

## القاعدة ٣ — تشريح الحقل المقدّس (Field)

لكل حقل إدخال (`Field` و`Textarea`) **ثلاثة عناصر مقدّسة (إلزاميّة)** — لا حقل بدونها، والمترجم TypeScript هو الحارس (أيّ نقص **يوقف البناء** ويشير للسطر):

1. **`icon`** — أيقونة هويّة بجانب التسمية، بخلفية **Aurora**: مربّع متراكز (`--radius-sm`) بتدرّج مائل 135° يتبع نغمة الحقل؛ خامل خفيف (50→شفّاف) ويقوى بتلاشٍ ناعم (100→شفّاف) عند **الاستخدام** (تركيز أو امتلاء).
2. **`innerIcon`** — أيقونة **داخل** مكان الكتابة (leading)، **مختلفة** عن أيقونة الـlabel (مكمّلة لها). خاملة رماديّة هادئة (`text-muted`)، وعند الاستخدام تتلوّن بنغمة الحقل (600) وتكبر قليلًا (`scale`).
3. **`placeholder`** — نصّ تلميحيّ داخل الحقل (يُفعّل كشف «ممتلئ» عبر `:placeholder-shown`).

- **الاختيار دلاليّ:** أيقونة الـlabel = معنى الحقل (اسم→`User` · بريد→`Envelope` · كلمة مرور→`Lock` · جوال→`Phone` · بحث→`MagnifyingGlass` · رابط→`LinkSimple` · اسم مستخدم→`At`)؛ والداخليّة **مكمّلة مختلفة** (اسم→`PencilSimple` · بريد→`At` · كلمة مرور→`Key` · جوال→`Hash` · اسم مستخدم→`IdentificationBadge`).
- **خلفية الحقل:** Aurora ناعمة لثلث الحقل (تينت `-50` يتلاشى للشفّاف عند 33% فوق السطح)، تتبع النغمة. **النصّ يبقى محايدًا عالي التباين** — الحالة تُقال بالحدّ والحلقة والأيقونات لا بلون القيمة (وصوليّة).
- **تفاعل «الحقل النشط»:** عند الاستخدام (تركيز/امتلاء) تضيء عناصر الحقل بنغمته معًا — أيقونة الـlabel (Aurora يقوى) · الأيقونة الداخليّة (لون النغمة + `scale`) · **تسمية الحقل العاديّ (تينت فولاذيّ عند التركيز فقط؛ الخطأ/النجاح يبقيان بلونهما)**.
- **الفرض والتطبيق:** الخصائص الثلاث إلزاميّة (لا `?`) في المكوّنين؛ التطبيق في كتل `.fld-lic` / `.fld-iic` / `.fld-in` بـ`components.css`.
- **البئر مُرمَّز المقاس وقابل لإعادة الاستخدام (شريط الأدوات نموذجًا):** أجزاء البئر (`.fld-in` · الأيقونة الأماميّة `.fld-iic` · زر السهم `.asel-chev`) تُستعمَل **خارج الحقل الكامل** عبر `.fld-wrap` وحده (بئر بلا تسمية)؛ لذا عُمِّم تفاعل الأيقونة الأماميّة على **`.fld-wrap`** لا `.fld`. ومقاس البئر **رمز** لا قيمة صريحة: **`--fld-h`** (ارتفاع، افتراض 48px) و**`--chev-sz`** (زر السهم، افتراض 26px). فالسياق المضغوط — **شريط الأدوات** — يستورد **مبدأ الحقل نفسه** (Aurora + حلقة تركيز + زر سهم) بضبط الرمزين مرّةً واحدة على الحاوية (`.tb { --fld-h: 40px; --chev-sz: 22px }`) — فيصغر البحث والمرشّح والسهم والمبدّل معًا، **مصدرًا واحدًا بلا نسخة مصغّرة**. النماذج تبقى على الافتراض (48px/26px).
- **استثناء منغَّم (التنبيه `.aalert`):** بقرار المالك، **عنوان** التنبيه مُلوَّن بلون النغمة (`--ac` = `tone-600`) — نبضة تمييز مقصودة تخالف مبدأ «النصّ محايد» أعلاه. أمّا **رسالة** التنبيه فتبقى محايدة (`--color-text`، تباين المحتوى). الاستثناء محصور بعنوان التنبيه وحده.

## القاعدة ٤ — حدّ الأسطح الموحّد (Card Stroke)

**المبدأ:** كل حدّ لسطح مؤطَّر (بطاقة · كرت عضو · بطاقة اختيار · أكورديون · شريط أدوات · قسم معرض…) من **رمز واحد لونًا وعرضًا** — لا `color-mix` ولا `#hex` ولا قيمة px شاردة للحدّ. مصدرٌ واحد يضبط الكلّ، فلا تعود شذوذات (كحدّ الـ10% الذي صُحّح، أو تشتّت 1px/1.5px).

**الرموز (في `tokens.css` — المصدر الوحيد):**
- **`--card-stroke`** = `--steel-200` ← لون الحدّ الخامل (فولاذيّ فاتح).
- **`--card-stroke-active`** = `--steel-500` ← لون الحدّ عند التفاعل (hover/اختيار) — فولاذيّ أعمق.
- **`--card-stroke-w`** = **`1.75px`** ← عرض الحدّ **الموحّد لكل الأسطح** (خامل ونشط) — قيمة واحدة لا تشتّت.
- **`--card-stroke-w-active`** = `1.75px` ← موحّد مع الأساس؛ التفاعل يغيّر **اللون لا العرض**.

**البُعد النغميّ (كـ `--shadow-tone` للظلّ):** السطح المنغّم لا يكتب `color-mix` خاصًّا لحدّه، بل رمزًا **موحّد الشدّة** (**30%** من نغمة‑600 ممزوجة بـ`--color-border`؛ البراند/الهويّة = `steel-500`):
- **`--card-stroke-brand`** · **`--card-stroke-neutral`** · **`--card-stroke-success`** · **`--card-stroke-warning`** · **`--card-stroke-danger`**. (النغمة المحايدة/الرماديّة = `--card-stroke-neutral` من `neutral-600`.)
- التطبيق: `border-color: var(--card-stroke-{tone})` — العرض 1.75px **موروث** (النغمة تغيّر اللون لا العرض). موحَّد على: `.acard-tone-*` · `.dt.dt-tone-*` · `.stat-*` · `.tt-*` · `.dm-tone-*` · `.mdl-tone-*`. غيّر الشدّة في `tokens.css` مرّةً → يتبع الكلّ. **استثناء:** `.aalert` يبقى على متغيّره `--ac` (نغمة متماسكة للتنبيه كاملًا).

**القاعدة عند أيّ سطح جديد:**
- الحدّ دائمًا → `border: var(--card-stroke-w) solid var(--card-stroke)`.
- عند hover/اختيار → **اللون فقط** يتحوّل إلى `--card-stroke-active` (العرض يبقى 1.75px موحّدًا).
- **ممنوع** أيّ عرض px صريح أو لون `color-mix`/`#hex` للحدّ — من الرموز فقط. غيّر `--card-stroke-w` أو `--card-stroke` في `tokens.css` → يتبع كلّ الأسطح.

**التطبيق (المصدر الوحيد):** كل سطح مؤطَّر يُسند الحدّ من الرمز — في `components.css`: `.acard` · `.mc` · `.ach-card` · `.aacc` · `.tb` · `.gal-sec` · `.mc-pager` · `.mc-empty`؛ وفي شاشات `globals.css`: `.cred-card` · `.auth-card` · `.st-card` · `.org-sec`. (وُحِّدت الأعراض على `--card-stroke-w` واللون على `--card-stroke`؛ صُحّحت شذوذات الـ10% و`--color-border`.) وأُعيد حدّ `card-stroke` للنافذة `.mdl` (النغميّة `.mdl-tone-*` بحدّها النغميّ من الرموز). **استثناءات:** عناصر التحكّم لا الأسطح (`.mdl-seg` · شرائح · شارات) تحتفظ بحدّها الخاصّ.

## القاعدة ٥ — الظلّ والحلقة (Shadow · Ring)

بدائيّتان **منفصلتان لا تُخلَطان**: **الظلّ = ارتفاع/عمق** · **الحلقة = حالة/تركيز (وصوليّة)**. كلٌّ له رموزه.

### أ) الظلّ — سلّم الارتفاع الموسوم بالنغمة

**المبدأ:** كل ظلّ من **سلّم واحد** (٣ مقاسات) × **نغمة العنصر** — لا `box-shadow` بقيمة صريحة في أيّ مكان. (وُحِّد كل ظلال الموقع على هذا السلّم بهذه الجلسة.)

**الرموز (في `tokens.css`):**
- **`--shadow-sm / --shadow-md / --shadow-lg`** = `0 … rgba(var(--shadow-tone), α)` (α = `.16 / .22 / .28`) ← المقاس/الارتفاع.
- **`--shadow-tone`** (افتراضيّ فولاذيّ = brand) + **`--shadow-tone-brand / success / warning / danger`** ← بُعد اللون.
- **حرِج جدًّا:** السلّم (والحلقات) مُعرّف على **`*` لا `:root`** — كي يُعيد كلّ عنصر حساب `var(--shadow-tone)` **بنغمته المحليّة**. تعريفه في `:root` يُجمّد النغمة عند الجذر فتصير كل الظلال فولاذيّة (فخّ CSS مثبَت تجريبيًّا بالمتصفّح). لا تنقله إلى `:root` أبدًا.

**المقاسات:** `sm` = عناصر صغيرة/لمسة · `md` = الكروت والأسطح (الافتراضيّ) · `lg` = النوافذ والطبقات العائمة.

**القاعدة عند أيّ عنصر:** يضبط `--shadow-tone` بنغمته الدلاليّة (أو يرث brand)، ويستعمل `var(--shadow-sm/md/lg)`. **ممنوع** أيّ `box-shadow` صريح. الاستثناء الوحيد: بدائيّات بنيويّة ليست عمقًا (حلقة أفتار بيضاء · شعرة `inset`) تُركَّب **بجانب** رمز السلّم لا بديلًا عنه. الوضع الداكن: السلّم أسود (النغمة لا تُقرأ على الداكن) — خارج نطاق الفاتح الحاليّ.

### ب) الحلقة — تركيز/حالة (لا عمق)

**المبدأ:** التركيز بدائيّة منفصلة (`0 0 0 3px` بلا إزاحة ولا بلور) — حالة ووصوليّة، **ليست ظلّ ارتفاع**، فلها رمزها الخاصّ لا سلّم الظلال.

**الرموز (على `*` كالسلّم):**
- **`--ring`** = `0 0 0 3px rgba(var(--shadow-tone), .16)` ← الحقول · الزنادات · حقل البحث.
- **`--ring-strong`** = `0 0 0 3px rgba(var(--shadow-tone), .28)` ← أهداف أكبر (عناصر الاختيار box/radio/switch).

**القاعدة:** الحقل/الزناد عند التركيز → `var(--ring)`؛ حالتا الخطأ/النجاح تضبطان `--shadow-tone` للنغمة فتحمرّ/تخضرّ الحلقة تلقائيًّا. الزناد المنسدل المفتوح (مركّب) = `var(--ring), var(--shadow-md)` (حلقة + إسقاط من السلّم). **ممنوع** أيّ حلقة بقيمة صريحة.
