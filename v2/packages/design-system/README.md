# ‎@adeeb/design-system — هويّة أدِيب على الويب

القانونُ في `v2/DESIGN.md`، وهذا الملفّ يصف الحزمة وحدها. **أساسُ الهويّة يُعاد بناؤه
(٢٠٢٦-١٠-٣٠):** رموزٌ جديدة بالبادئة `--ad-*` وأصنافٌ بالبادئة `.ad-*`، بوضعين فاتحٍ وداكن.
ثمّ تُنقل الغرف إليها قالبًا قالبًا، ويخرج القديم.

## الملفّات
| الملفّ | الدور |
|------|-------|
| `tokens.css` | الرموز: سلالم اللون (كحليّ، فولاذيّ، محايد، ونغمات الحالة)، والخطّ، والمسافات، والزوايا، والظلال، والحركة. |
| `fonts.css` | `@font-face` لخطّي العلامة: Lyon Arabic للعربيّ، وEras للاتينيّ والأرقام. |
| `components.css` | مكتبة الأصناف المشتركة، ويستهلكها التطبيق. |
| `tokens.ts` | قيمٌ قليلة بصيغة TS لما يحتاجها في JavaScript (لون البيان، وألوان الرسم في الأكواد). |
| `src/` | مكوّنات React (`Button`، `Field`، `Modal`…) ودوالّ مساعدة. |
| `fonts/` و`brand/` | ملفّات الخطوط، والشعار والنقش بصيغة SVG. |

## الحرّاس
`pnpm check` في جذر `v2/`، ومنه **سقّاطة الهويّة** (`scripts/identity-ratchet.mjs`):
عدّاداتُ ما يُكتب خارج النظام لا تصعد أبدًا.

> **Tailwind يُحذف من المشروع** بقرار محمد. لا يُضاف منه صنف، وسلّمُ أحجامه المنسوخ
> (`--text-*`) يخرج مع نزول السلّم الجديد.
