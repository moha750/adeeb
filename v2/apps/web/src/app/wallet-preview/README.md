## ما تعرضه الصفحة

`/wallet-preview` — علنيّةٌ بلا حساب (ولا تُفهرَس في محرّكات البحث):

1. **البطاقة** كما يعرضها Apple Wallet، بوجهٍ وظهرٍ يُقلَبان.
2. **مبدّل حساباتٍ وهميّة** — أربعةٌ تغطّي قمّة السلّم ووسطه وأوّله ومن لم يبلغ عتبةَ
   أوّل عرضٍ بعد.
3. **سلّم الرتب** — الرتبة تُشتقّ من الرصيد ولا تُمنَح.
4. **عروض الرعاة** — تُستبدَل بالنقاط أمام العين: الرصيد يهبط، وقد تسقط الرتبةُ معه،
   فتُقفَل عروضٌ كانت مفتوحة.
5. **سجلّ الإنجازات** — مرصودةً يدويًّا باسم من رصدها.
6. **زرّ «أضِف إلى Apple Wallet»** — يولّد `.pkpass` **موقَّعًا فعلًا**.

## تشغيل التوقيع الحقيقيّ

الشهادة التي بيدك اليوم شهادةُ **مطوّر**، وهي **غير** شهادة نوع البطاقة. من الحساب نفسه:

1. في [بوّابة أبل](https://developer.apple.com/account/resources/identifiers/list/passTypeId)
   أنشئ **Pass Type ID** (مثل `pass.club.adeeb.loyalty`).
2. أصدِر له **Pass Type ID Certificate**، ونزّل `.cer` ثمّ حوّله مع مفتاحه إلى PEM:

   ```bash
   openssl x509 -inform DER -in pass.cer -out pass-cert.pem
   openssl pkcs12 -in pass.p12 -nocerts -nodes -out pass-key.pem   # المفتاح
   ```

3. نزّل **Apple WWDR G4** وحوّلها:

   ```bash
   openssl x509 -inform DER -in AppleWWDRCAG4.cer -out wwdr.pem
   ```

4. ضع في `.env.local` (خمسةٌ إلزاميّة وسادسٌ اختياريّ):

   ```
   WALLET_PASS_TYPE_ID=pass.club.adeeb.loyalty
   WALLET_TEAM_ID=XXXXXXXXXX
   WALLET_PASS_CERT_PEM="-----BEGIN CERTIFICATE-----\n…"
   WALLET_PASS_KEY_PEM="-----BEGIN PRIVATE KEY-----\n…"
   WALLET_WWDR_PEM="-----BEGIN CERTIFICATE-----\n…"
   WALLET_PASS_KEY_PASSPHRASE=…        # إن كان المفتاح مشفَّرًا
   ```

**وقبل ذلك لا تُخرَج حزمةٌ نصفُ موقَّعة**: الزرّ يردّ ٥٠٣ ويسمّي المتغيّر الناقص بعينه —
لأنّ حزمةً غير موقَّعة يرفضها الجهازُ بصمتٍ فيضيع الوقت في التخمين.

**شعارٌ اختياريّ**: ضع `public/brand/wallet/logo.png` (و`logo@2x.png`) فيُلتقط تلقائيًّا؛
وبدونه تكتفي البطاقة بـ`logoText`. والأيقونةُ مُولَّدةٌ بتدرّج الهوية — استبدلها متى
صدَّرتَ أيقونةً حقيقيّة.

## ما تحقّق منه فعلًا

- **التوقيع**: `openssl cms -verify` يقبله، ويسقط إن عُبث بالمانيفست بايتًا واحدًا.
- **الحزمة**: `unzip -t` يفكّها، وكلُّ بصمةِ SHA-1 في `manifest.json` تطابق ملفَّها.
- **الأيقونة**: توقيعُ PNG وكتلُه الثلاث سليمة، وIDAT تُفَكّ إلى الطول المتوقَّع.
- **الواجهة**: الاستبدال يهبط بالرصيد ويسقط بالرتبة ويُقفل ما لم تعد تفتحه.

**ما لم يُجرَّب**: فتحُ الملفّ على أيفون فعليّ — يلزمه شهادةٌ حقيقيّة، وهي عندك لا عندي.

## إن قُرِّر بناؤه نظامًا حقيقيًّا

لا يُرقَّى هذا المجلّد، بل يُقرأ ثمّ يُحذف. النظام الحقيقيّ يحتاج ما تعمّدنا تركَه:
جدولَي نقاطٍ وعروض، وقدرةَ رصدٍ في `permissions`، و RLS، ودالّةَ رصدٍ `SECURITY DEFINER`
تُقيّد في `activity_log`، وخدمةَ تحديثٍ (`webServiceURL`) تُحدّث البطاقة في الجهاز حين
يتغيّر الرصيد. ولا شيءَ من ذلك هنا عمدًا — المعاينةُ تُري الفكرةَ ولا تدّعي النظام.
