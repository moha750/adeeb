# صورُ الروابط

كلُّ صورةٍ تظهر في بطاقة الرابط (واتساب · إكس · تيليجرام · لينكدإن) تسكن هنا، ولا تسكن
في غيره. وهذا المجلّد هو موضعُ الوضع: ضع الملفَّ بالاسم المكتوب في الجدول، ثمّ قل لي
«خذها» فأربطها بصفحتها.

## المواصفة

| البند | القيمة |
| --- | --- |
| المقاس | **١٢٠٠×٦٣٠** بالضبط (نسبة ١٫٩١:١) |
| الصيغة | `png` أو `jpg` |
| الوزن | **دون ٦٠٠ كيلوبايت** — واتساب يتخلّى عن المعاينة فوقها |
| النصّ فيها | كبيرًا: البطاقةُ تُعرَض بعرض ٣٠٠ بكسل في قائمة المحادثات |

## الأسماء

| الملفّ | الصفحة | الحال |
| --- | --- | --- |
| `adeeb.png` | الافتراضيّة: كلُّ صفحةٍ لا صورةَ لها | ✅ موضوعة |
| `home.png` | الرئيسيّة `/` | في انتظارها |
| `news.png` | قائمة الأخبار `/news` | في انتظارها |
| `radio.png` | الإذاعة `/radio` | ✅ موضوعةٌ ومربوطة (مربّعة ١٢٠٠×١٢٠٠ بقرار المالك ٢٠٢٦-٠٩-١٨) |
| `show.png` | صفحاتُ البرامج `/radio/<برنامج>` | في انتظارها |
| `episode.png` | صفحاتُ الحلقات `/radio/<برنامج>/<حلقة>` | في انتظارها |
| `darb.jpg` | «دربك خضر» `/games/darbak-khadar` وما تحته | ✅ موضوعةٌ ومربوطة: مشهدُ اللعبة نفسِها بلا اسم النادي (هويّتُها منعزلة) |
| `library.png` | المكتبة `/library` | في انتظارها |
| `book.png` | صفحاتُ الكتب `/library/<كتاب>` | في انتظارها |
| `works.png` | الأعمال `/works` | في انتظارها |
| `activities.png` | الفعاليّات `/activities` | في انتظارها |
| `deebo.png` | ديبو `/deebo` | في انتظارها |
| `join.png` | الانضمام `/join` | في انتظارها |
| `surveys.png` | الاستبيانات `/surveys/<استبيان>` | في انتظارها |
| `profile.png` | بطاقاتُ الأعضاء `/m/<عضو>` | في انتظارها |

ولستَ ملزَمًا بواحدةٍ منها: ما لم تضعه تأخذ صفحتُه `adeeb.png`.

## ما لا يسكن هنا

**غلافُ الخبر.** رابطُ كلّ خبرٍ يحمل غلافَ الخبر نفسِه المرفوعَ من لوحة التحرير
(قرارُ المالك ٢٠٢٦-٠٩-١٧)، فلا يُوضَع له ملفٌّ هنا. و`news.png` أعلاه لقائمة
الأخبار وحدَها لا لخبرٍ بعينه.

## كيف تُربَط

المصدرُ الواحد `src/lib/share.ts`: صفحةٌ تمرّر `images` تفوز بصورتها، ومن لا تمرّر
تنال `adeeb.png`. فالربطُ سطرٌ واحدٌ لكلّ صفحة، ولا تُنسَخ مساراتُ الصور في الشاشات.
